# QT-Audio-Player
A simple and horribly optimized Qt-based audio player that I am creating to learn C++.

# Features
practically nothing right now.
if you load music into the audio folder, it will play in order.
you have some basic media controls like back/forward 5 seconds and skipping back/forth.
but that's it, it's not even close to finished!

# Instructions
Have CMake. \n
Open build folder in a terminal. \n
Compile with CMake. \n
Run the executable.
